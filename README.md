# Kukio Skins Prices Public

公開用の静的サイトです。

## Cloudflare Pages設定

- Framework preset: None
- Build command: 空欄
- Build output directory: /
- Root directory: 空欄または /

## アップロードするファイル

- `index.html`
- `styles.css`
- `app.js`
- `skins-data.js`

`functions` フォルダ、D1、R2、ADMIN_PASSWORD は不要です。

## データ更新

管理版で書き出した `skins-data.js` を、この公開版の `skins-data.js` と差し替えると公開データが更新されます。
